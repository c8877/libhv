### 字段

```
名称        必填，同类分组唯一，≤64
描述        可选，≤256
客户端用户  来自 clients.txt 或管理台 client 账号列表
ACL         客户端分组 → 设备分组
```

### ACL 编辑器

行结构：

```
设备分组 | TCP 端口 | Shell | TTY | 文件 | SYSINFO | 指标 | 配置 | Web | 移除
```

- 设备分组：下拉选择，已添加的不能重复。
- TCP 端口：文本，支持 `22,80,8000-8100,*`。
- Shell：复选框。
- TTY：文本，支持 `ttyS*,ttyUSB0`。
- 文件：`none / ro / rw`。
- SYSINFO / 指标 / 配置 / Web：复选框。
- 移除：删除该 ACL 条目。

保存时整组提交：

```
PUT /api/v1/permission/client-groups/:id
{
  "name": "研发组",
  "description": "...",
  "users": ["alice","bob"],
  "acl": [
    {
      "agent_group_id": 1,
      "tcp_ports": "22,80",
      "shell": false,
      "tty": "",
      "file": "ro",
      "sysinfo": true,
      "metrics": true,
      "config": false,
      "web": false
    }
  ]
}
```

### 数据来源

左侧候选集由三部分合并，按 devid 去重：

```
1. relay 当前在线 agent
2. admin devices 表登记过的设备
3. 已存在于其他设备分组的历史成员
```

排序：

```
在线优先
最近活跃优先
devid 字典序
```

每行显示：

```
devid
在线/登记状态
已属其他分组（只读标签，不影响加入）
```

已经在当前分组内的设备不出现在左侧。

### 穿梭操作

| 控件 | 行为 |
|---|---|
| `>` | 把左侧勾选设备移到右侧 |
| `>>` | 把左侧当前筛选结果全部移到右侧 |
| `<` | 把右侧勾选设备移回左侧 |
| `<<` | 清空右侧，全部回到左侧 |
| 双击行 | 单台快速穿梭 |
| 复选框 | 多选 |

规则：

- 左右列表都支持搜索。
- 「仅在线」只影响左侧候选。
- 右侧允许包含离线设备；确认时提示。
- 同一 devid 不能重复出现在右侧。
- 当前分组已有成员不进入候选。
- 关闭弹窗不保存；点击确定才提交。

### 空状态

```
可选设备为空
┌────────────────────────────────────┐
│ 没有可添加的设备                   │
│ 先让 agent 上线，或在设备页绑定设备 │
└────────────────────────────────────┘
```

```
已选为空
┌────────────────────────────────────┐
│ 从左侧勾选设备后点 [ > ]            │
└────────────────────────────────────┘
```

### 确认

```
[确定添加 3 台]
→ POST /api/v1/permission/agent-groups/:id/devices
   { "devids": ["dev4","dev5","dev6"] }
→ 成功后关闭穿梭框，刷新当前分组行
→ 失败保持弹窗并显示错误
```

后端要求：

- 整批校验；
- 已存在成员幂等忽略；
- 非法 devid 拒绝整批，不产生半写入。

### 候选 API

```text
GET /api/v1/permission/agent-groups/:id/candidates?q=&online=1
```

返回：

```json
{
  "devices": [
    { "devid": "dev1", "online": true, "source": "online", "groups": ["产线B"] },
    { "devid": "dev2", "online": false, "source": "registered", "groups": [] }
  ]
}
```

# 6. 交互规则

## 展开/收起

```
点击行        展开
再次点击      收起
点击另一行    先收起当前行，再展开新行
```

有未保存修改时：

```
当前行有修改，切换/收起？
[继续编辑] [放弃修改]
```

## 保存

```
保存按钮只提交当前展开行
成功 → 收起或保留展开（建议保留）
失败 → 行内错误，不关闭
```

## 删除

```
[删除分组]
→ 确认弹窗
→ 客户端分组：提示会删除成员和 ACL
→ 设备分组：被引用时拒绝删除，提示引用它的客户端分组
```

## 添加用户

允许输入：

```
alice
alice,bob
```

不存在的用户：

```
行内提示：用户 alice 不在 clients.txt
```

是否阻止保存由后端决定，前端先提示。

## 添加设备

允许输入：

```
dev1
dev1,dev2
```

设备可以离线或未上线，标记为「未知」但允许保存。

## ACL 上限冲突

如果 ACL 配置超过设备分组上限：

```
┌ 警告 ──────────────────────────────────────────┐
│ 调试设备组能力上限不含 8000-8100                │
│ 保存后实际权限会被裁剪                          │
└────────────────────────────────────────────────┘
```

默认允许保存，但显示黄色提示。

# 11. 实现建议

页面组件拆分：

```
PermissionPage
├─ PermissionTabs
├─ ClientGroupTable
│   └─ ClientGroupRow
│       └─ ClientGroupForm
│           ├─ ClientMembers
│           └─ AclEditor
├─ AgentGroupTable
│   └─ AgentGroupRow
│       └─ AgentGroupForm
│           ├─ AgentMembers
│           └─ AgentCapabilityForm
└─ EffectivePreview
```

行内展开不能每行一个独立 DOM 副本，使用：

```
expandedKey = "client:1" | "agent:3"
```

同一时间只渲染一个展开表单。
